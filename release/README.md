# Release artifact / Артефакт релиза

`teoria-helper-1.0.0.zip` is the Chrome Web Store upload package for version `1.0.0`. Release packages are committed to this directory so every published version remains available in the repository.

`teoria-helper-1.0.0.zip` — пакет версии `1.0.0` для загрузки в Chrome Web Store. Релизные пакеты сохраняются в этом каталоге и добавляются в Git, чтобы каждая опубликованная версия оставалась доступна в репозитории.
