# Privacy Policy / Политика конфиденциальности

Effective date / Дата вступления в силу: 16 July 2026 / 16 июля 2026 г.

## English

Teoria Helper does not collect, store, transmit, share, or sell personal data, browsing history, or page content.

The extension runs only on Teoria.on.ge ticket and exam pages. It locally reads the current ticket number, the language selected on the website, and the visible answer order. This is necessary to select bundled help content and, in exam mode, report the correct answer's current shuffled position. The information never leaves the user's device.

The extension:

- contains no analytics, advertising, tracking, accounts, or telemetry;
- uses no cookies, browser storage, or remote code;
- makes no network requests of its own;
- does not sell or share data with anyone;
- requests no Chrome API permissions.

Its content script is restricted to `https://teoria.on.ge/tickets*` and `https://teoria.on.ge/exam*`. Normal requests made by the Teoria website itself are outside the extension's control.

Questions about this policy can be submitted through the repository's [GitHub Issues](https://github.com/metacircu1ar/teoria_helper/issues).

## Русский

Teoria Helper не собирает, не хранит, не передаёт, не предоставляет третьим лицам и не продаёт персональные данные, историю посещений или содержимое страниц.

Расширение работает только на страницах билетов и экзамена Teoria.on.ge. Оно локально считывает номер текущего билета, выбранный на сайте язык и видимый порядок вариантов ответа. Это необходимо, чтобы выбрать встроенную справку и в режиме экзамена указать текущую позицию правильного ответа после перемешивания. Эти сведения не покидают устройство пользователя.

Расширение:

- не содержит аналитики, рекламы, отслеживания, учётных записей или телеметрии;
- не использует cookie, хранилище браузера или удалённый код;
- не выполняет собственных сетевых запросов;
- никому не продаёт и не передаёт данные;
- не запрашивает разрешений Chrome API.

Скрипт расширения работает только по адресам `https://teoria.on.ge/tickets*` и `https://teoria.on.ge/exam*`. Обычные запросы самого сайта Teoria находятся вне контроля расширения.

Вопросы по этой политике можно задать через [GitHub Issues](https://github.com/metacircu1ar/teoria_helper/issues) репозитория.
